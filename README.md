# Анализ маркетинговых кампаний

Исследование данных о рассылках (email, push): как характеристики кампаний
и сообщений влияют на открываемость.

## Сделано
- EDA признаков кампаний и сообщений (pandas, NumPy, Matplotlib, Seaborn)
- Проверка качества и согласованности данных (соответствие типа сообщения типу кампании)
- Feature engineering: тип дня отправки (выходной/праздник по holidays.csv),
  время дня, группировка редких категорий email-провайдеров, признаки темы пма
- Отбор информативных признаков (L1-регуляризация)
- Классификация открытия сообщения: precision, recall, F1, важность признаков

 Стек
Python, pandas, NumPy, SciPy, scikit-learn, Matplotlib, Seaborn

## Структура
- `code/gp.ipynb` - основной ноутбук с анализом
- `data/campaigns.csv` - данные о кампаниях и сообщениях
- `data/holidays.csv` - праздничные дни
